= DataScienceCluster

Activa solo lo que usa este lab. En la pestaña *YAML* del create, reemplaza todo el manifiesto por el de abajo.

* `Managed`: `dashboard`, `workbenches`, `kserve`, `aipipelines`, `modelregistry`, `aigateway`
* `Unmanaged`: `kueue`
* `Removed`: el resto (`ogx`, `sparkoperator`, `feastoperator`, `trustyai`, `ray`, `mlflowoperator`, `trainer`, `nim`, `llamastackoperator`, `trainingoperator`, …)
* `aigateway.modelsAsAService` queda en `Removed` hasta Connectivity Link + gateway + Postgres

== YAML final

Pestaña *YAML* → pega esto → *Create*:

[source,yaml]
----
apiVersion: datasciencecluster.opendatahub.io/v2
kind: DataScienceCluster
metadata:
  name: default-dsc
  labels:
    app.kubernetes.io/name: datasciencecluster
spec:
  components:
    ogx:
      managementState: Removed
    sparkoperator:
      managementState: Removed
    kserve:
      wva:
        managementState: Removed
      rawDeploymentServiceConfig: Headless
      nim:
        airGapped: false
        managementState: Removed
      modelCache:
        managementState: Removed
      modelsAsService:
        managementState: Removed
      managementState: Managed
    modelregistry:
      registriesNamespace: rhoai-model-registries
      managementState: Managed
    feastoperator:
      managementState: Removed
    trustyai:
      eval:
        lmeval:
          permitCodeExecution: deny
          permitOnline: deny
      mcpGuardrailsMode: false
      managementState: Removed
    aipipelines:
      argoWorkflowsControllers:
        managementState: Managed
      managementState: Managed
    ray:
      managementState: Removed
    kueue:
      autoCreateQueues: false
      defaultClusterQueueName: default
      defaultLocalQueueName: default
      managementState: Unmanaged
    workbenches:
      workbenchNamespace: rhods-notebooks
      managementState: Managed
    mlflowoperator:
      managementState: Removed
    dashboard:
      managementState: Managed
    trainer:
      managementState: Removed
    llamastackoperator:
      managementState: Removed
    aigateway:
      managementState: Managed
      modelsAsAService:
        managementState: Removed
    trainingoperator:
      managementState: Removed
----

== Verificar

[source,bash]
----
oc get dsc
oc get pods -n redhat-ods-applications
----

Espera a que `default-dsc` esté `Ready` (5–15 min). Debe existir el dashboard:

[source,bash]
----
oc get route -n redhat-ods-applications
----

Abre la ruta `rhods-dashboard` / `rhoai` como `admin` (no `kubeadmin`).
