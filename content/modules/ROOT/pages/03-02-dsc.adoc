= DataScienceCluster

El `DataScienceCluster` (`default-dsc`) activa los componentes de OpenShift AI que usa este lab.
Deja en `Managed` solo lo necesario; el resto queda `Removed` (o `Unmanaged` en el caso de Kueue, que ya instalaste como Operator en pre-requisitos).

NOTE: `ogx` en `Managed` es requisito del *Gen AI Studio → Playground*. Sin OGX, la UI puede listar endpoints pero no ofrece Playground.

== Componentes de este lab

[cols="1,1,2"]
|===
|Componente |Estado |Para qué sirve

|`dashboard`
|Managed
|Consola web de OpenShift AI (ruta `rhods-dashboard` / `rhoai`).

|`workbenches`
|Managed
|Notebooks / workbenches en `rhods-notebooks`.

|`kserve`
|Managed
|Serving de modelos (InferenceServices / llm-d). Subcomponentes NIM, model cache y `modelsAsService` quedan `Removed`.

|`aipipelines`
|Managed
|AI Pipelines (Argo) sobre OpenShift Pipelines.

|`modelregistry`
|Managed
|Model Registry (namespace `rhoai-model-registries`).

|`aigateway`
|Managed
|AI Gateway. `modelsAsAService` queda `Removed` hasta Connectivity Link + gateway + Postgres (módulo 4).

|`ogx`
|Managed
|Motor del *Gen AI Studio → Playground*.

|`kueue`
|Unmanaged
|Usa el Operator de Kueue ya instalado (GPU Booking); el DSC no gestiona el Operator.

|`sparkoperator`
|Removed
|No se usa en este lab.

|`feastoperator`
|Removed
|Feature store; fuera de alcance.

|`trustyai`
|Removed
|EvalHub / TrustyAI se habilitan más adelante (módulo 12).

|`ray`
|Removed
|Distributed training Ray; fuera de alcance.

|`mlflowoperator`
|Removed
|MLflow se activa con EvalHub (módulo 12).

|`trainer` / `trainingoperator`
|Removed
|Training operators; fuera de alcance.

|`llamastackoperator`
|Removed
|Llama Stack; fuera de alcance.
|===

== Instalar por terminal

Desde la raíz del repo (crea o actualiza `default-dsc`):

[source,bash]
----
oc apply -f manifests/default-dsc.yaml
----

Para seguir el estado:

[source,bash]
----
oc get dsc default-dsc -w
----

== Verificar

[source,bash]
----
oc get dsc
oc get pods -n redhat-ods-applications
----

Espera a que `default-dsc` esté `Ready` (5–15 min). Condición `OGXReady=True` y pod del operator OGX en `redhat-ods-applications`:

[source,bash]
----
oc get dsc default-dsc -o jsonpath='{.status.conditions[?(@.type=="OGXReady")].status}{"\n"}'
oc get pods -n redhat-ods-applications -l name=ogx-k8s-operator
----

Debe existir el dashboard:

[source,bash]
----
oc get route -n redhat-ods-applications
----

Abre la ruta `rhods-dashboard` / `rhoai` como `admin` (no `kubeadmin`).
