= ODHDashboardConfig

Este recurso controla qué menús y funciones aparecen en el dashboard de OpenShift AI.
Con el patch de este lab se activan las piezas que usarás más adelante (catálogo, MaaS, Gen AI Studio, Evaluations y Kueue). *No* se habilita `vLLMDeploymentOnMaaS`: aquí se despliega con *llm-d*.

NOTE: *Gen AI Studio → Playground* también exige `ogx: Managed` en el `DataScienceCluster` (xref:03-02-dsc.adoc[DataScienceCluster]). *Evaluations* exige TrustyAI + EvalHub (xref:12-00-evalhub.adoc[módulo 12]) y, para la UI completa, MLflow.

== Qué se activa

[cols="1,2"]
|===
|Flag |Efecto

|`disableModelCatalog: false`
|Muestra el *Model Catalog*.

|`disableModelRegistry: false`
|Muestra el *Model Registry*.

|`disableKueue: false`
|Habilita la UI de Kueue / GPU Booking en el dashboard.

|`modelAsService: true`
|Muestra *Models as a Service* (MaaS).

|`genAiStudio: true`
|Muestra *Gen AI Studio* (Playground cuando OGX está listo).

|`disableLMEval: false`
|Habilita el menú *Evaluations* (EvalHub; se usa en el módulo 12).

|`observabilityDashboard: true`
|Habilita *Observe & monitor* / dashboards (incl. *Usage* MaaS, Technology Preview).
|===

== Instalar por terminal

[source,bash]
----
oc patch odhdashboardconfig odh-dashboard-config -n redhat-ods-applications --type merge -p '{
  "spec": {
    "dashboardConfig": {
      "disableModelCatalog": false,
      "disableModelRegistry": false,
      "disableKueue": false,
      "modelAsService": true,
      "genAiStudio": true,
      "disableLMEval": false,
      "observabilityDashboard": true
    }
  }
}'
----

Hard refresh del dashboard de OpenShift AI (`Cmd+Shift+R` / `Ctrl+Shift+R`).

== Verificar

[source,bash]
----
oc get odhdashboardconfig odh-dashboard-config -n redhat-ods-applications \
  -o jsonpath='{.spec.dashboardConfig}' | jq
----

En el dashboard deben verse *Catalog* / *Models as a Service* (el nombre exacto depende de la build).
