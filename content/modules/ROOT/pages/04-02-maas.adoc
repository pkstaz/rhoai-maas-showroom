= Habilitar MaaS

Orden:

. Postgres + secret `maas-db-config`
. Gateway `maas-default-gateway`
. `aigateway.modelsAsAService: Managed` en el DSC

== 1. Base de datos

[source,bash]
----
oc apply -f examples/maas-postgres.yaml
oc get pods -n redhat-ai-gateway-infra
----

Espera el pod de Postgres `Running`. El YAML crea el Secret `maas-db-config`.

== 2. Gateway

[source,bash]
----
bash examples/apply-maas-gateway.sh
oc get gateway maas-default-gateway -n openshift-ingress
----

`Programmed` = `True`.

== 3. Encender MaaS en el DSC

=== UI

. *Installed Operators* → *Red Hat OpenShift AI* → *DataScienceCluster* → `default-dsc` → *YAML*
. En `spec.components.aigateway`:

[source,yaml]
----
aigateway:
  managementState: Managed
  modelsAsAService:
    managementState: Managed
----

. *Save*

=== YAML

[source,bash]
----
oc patch dsc default-dsc --type merge -p '{
  "spec": {
    "components": {
      "aigateway": {
        "managementState": "Managed",
        "modelsAsAService": { "managementState": "Managed" }
      }
    }
  }
}'
----

== Verificar

[source,bash]
----
oc get dsc default-dsc
oc get pods -n redhat-ai-gateway-infra
oc get pods -n redhat-ods-applications | grep -i maas
oc get aitenant -A
oc get maastenantconfig -A
----

`maas-api` / `maas-controller` en `Running`.
