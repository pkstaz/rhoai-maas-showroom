= Desplegar Qwen3-0.6B (llm-d, CPU, MaaS)

Despliega Qwen en *CPU* con un manifiesto limpio (sin wizard): `LLMInferenceService` + `MaaSModelRef`.
Queda visible en el AI Hub / Gen AI Studio (*AI asset endpoints*) y publicado en MaaS.

Requisitos: MaaS encendido (módulo 4), profile `cpu-workshop` (módulo 3), gateway `maas-default-gateway`.
Manifiesto: `manifests/llminferenceservice-qwen3-06b.yaml`.

== Qué crea el manifiesto

[cols="1,2"]
|===
|Recurso |Detalle

|Namespace `llm`
|Proyecto de Data Science + acceso al gateway MaaS.

|`LLMInferenceService/qwen3-06b`
|llm-d + imagen `vllm-cpu-rhel9:3.5.0`, `max-model-len=2048`, label `opendatahub.io/genai-asset=true`.

|`MaaSModelRef/qwen3-06b`
|Publica el modelo en Models as a Service.
|===

== Instalar por terminal

Desde la raíz del repo:

[source,bash]
----
oc apply -f manifests/llminferenceservice-qwen3-06b.yaml
----

== Esperar Ready

[source,bash]
----
printf '%-36s %-12s %s\n' "RECURSO" "ESTADO" "DETALLE"
printf '%-36s %-12s %s\n' "------------------------------------" "------------" "----------------"

oc wait --for=condition=Ready llminferenceservice/qwen3-06b -n llm --timeout=900s >/dev/null 2>&1 && \
  printf '%-36s %-12s %s\n' "LLMInferenceService/qwen3-06b" "OK" "Ready" || \
  printf '%-36s %-12s %s\n' "LLMInferenceService/qwen3-06b" "PENDIENTE" "$(oc get llminferenceservice qwen3-06b -n llm -o jsonpath='{.status.conditions[?(@.type=="Ready")].reason}' 2>/dev/null || echo '?')"

img=$(oc get deploy -n llm -o jsonpath='{range .items[*]}{.spec.template.spec.containers[0].image}{"\n"}{end}' 2>/dev/null | grep -m1 vllm || true)
echo "$img" | grep -q 'vllm-cpu' && \
  printf '%-36s %-12s %s\n' "Imagen serving" "OK" "vllm-cpu" || \
  printf '%-36s %-12s %s\n' "Imagen serving" "REVISAR" "${img:-sin deploy}"

oc get maasmodelref qwen3-06b -n llm --no-headers 2>/dev/null | grep -qi Ready && \
  printf '%-36s %-12s %s\n' "MaaSModelRef/qwen3-06b" "OK" "Ready" || \
  printf '%-36s %-12s %s\n' "MaaSModelRef/qwen3-06b" "PENDIENTE" "espera subscription (módulo 9) o reconciliación"
----

== Verificar en UI

* *Gen AI Studio* → *AI asset endpoints* (proyecto `llm`): debe listar el modelo (`opendatahub.io/genai-asset=true`).
* *Models as a Service*: el `MaaSModelRef` `qwen3-06b` (pasa a `Ready` tras la subscription del módulo 9).

[source,bash]
----
oc get llminferenceservice -n llm
oc get pods -n llm
oc get maasmodelref -n llm -o wide
oc get llminferenceservice qwen3-06b -n llm -o jsonpath='{.metadata.labels.opendatahub\.io/genai-asset}{"\n"}'
----

NOTE: El vLLM CPU del lab usa `max_model_len=2048`. En Playground / chat usa `max_tokens` ≤ 1024 y `/no_think`.
