= GatewayClass y Kuadrant

El Operator de Connectivity Link quedó en `openshift-operators` (módulo 2). La instancia *Kuadrant* se crea en **`kuadrant-system`**: ahí corren Authorino y Limitador.

== 1. GatewayClass

[source,bash]
----
oc apply -f examples/gatewayclass.yaml
oc get gatewayclass openshift-default
----

`GatewayClass` es de *cluster* (sin namespace). `ACCEPTED` = `True` basta.

== 2. Controller name (OpenShift)

Kuadrant espera el controller de Istio/Envoy. En este lab hay que apuntarlo al de OpenShift:

[source,bash]
----
oc patch subscription rhcl-operator -n openshift-operators --type merge -p '{
  "spec": {
    "config": {
      "env": [{
        "name": "ISTIO_GATEWAY_CONTROLLER_NAMES",
        "value": "openshift.io/gateway-controller/v1"
      }]
    }
  }
}'

oc get deploy -n openshift-operators -o name | grep -i kuadrant
oc rollout restart -n openshift-operators \
  $(oc get deploy -n openshift-operators -o name | grep -i kuadrant)
----

Espera a que el pod del operator vuelva a `Running`.

== 3. Instancia Kuadrant

=== UI

. *Home* → *Projects* → *Create Project* → `kuadrant-system`
. Cambia el proyecto de la consola a `kuadrant-system`
. *Ecosystem* → *Installed Operators* → *Red Hat Connectivity Link*
. Pestaña *Kuadrant* → *Create Kuadrant*
. Nombre: `kuadrant` (la UI propone `kuadrant-sample`; cámbialo)
. *Create*

=== YAML

[source,bash]
----
oc create namespace kuadrant-system
oc apply -f examples/kuadrant.yaml
oc wait kuadrant/kuadrant -n kuadrant-system --for=condition=Ready --timeout=5m
----

== Verificar

[source,bash]
----
oc get kuadrant -n kuadrant-system
oc get pods -n kuadrant-system
----

`Ready` y pods de Authorino / Limitador `Running`.
