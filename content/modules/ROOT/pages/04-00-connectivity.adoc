= GatewayClass y Kuadrant

El Operator de Connectivity Link queda en `openshift-operators` (módulo 2). Al crear el `GatewayClass`, el Ingress Operator instala Service Mesh 3 (`istiod-openshift-gateway` en `openshift-ingress`). Después se crea la instancia *Kuadrant* en **`kuadrant-system`**.

== 1. GatewayClass

[source,bash]
----
oc apply -f examples/gatewayclass.yaml
oc wait --for=condition=Accepted gatewayclass/openshift-default --timeout=2m
oc rollout status -n openshift-ingress deploy/istiod-openshift-gateway --timeout=5m
oc delete pod -n openshift-operators \
  $(oc get pods -n openshift-operators -o name | grep kuadrant-operator-controller-manager)
oc rollout status -n openshift-operators deploy/kuadrant-operator-controller-manager --timeout=3m
----

`GatewayClass` es de *cluster*. El Ingress Operator deja `istiod-openshift-gateway` `Available`. El Operator de Kuadrant se recarga después de eso para detectar el Gateway API provider.

== 2. Instancia Kuadrant

=== UI

. *Home* → *Projects* → *Create Project* → `kuadrant-system`
. Cambia el proyecto de la consola a `kuadrant-system`
. *Ecosystem* → *Installed Operators* → *Red Hat Connectivity Link*
. Pestaña *Kuadrant* → *Create Kuadrant*
. Nombre: `kuadrant`
. En `spec` deja:

[source,yaml]
----
spec:
  observability:
    enable: true
----

. *Create*

=== YAML

[source,bash]
----
oc create namespace kuadrant-system
oc apply -f examples/kuadrant.yaml
oc wait kuadrant/kuadrant -n kuadrant-system --for=condition=Ready --timeout=5m
----

== Verificar

[source,bash]
----
oc get kuadrant -n kuadrant-system
oc get pods -n kuadrant-system
----

`Ready`. Pods de Authorino y Limitador `Running`.

== Troubleshooting

=== Kuadrant: *Gateway API provider (istio / envoy gateway) is not installed*

Si creaste la instancia *antes* de que `istiod-openshift-gateway` estuviera listo, el Operator de Kuadrant no detecta el provider. Con Istio ya instalado, basta reiniciar el controller:

[source,bash]
----
oc delete pod -n openshift-operators \
  -l control-plane=controller-manager \
  --field-selector=status.phase=Running
----

Espera el rollout y vuelve a chequear la instancia:

[source,bash]
----
oc rollout status -n openshift-operators deploy/kuadrant-operator-controller-manager --timeout=3m
oc get kuadrant -n kuadrant-system
----
