= Monitoreo (user workloads)

Actívalo *antes* del Operator de OpenShift AI. El dashboard y Kueue usan métricas de user-workload monitoring.

== UI

. *Home* → *Search* → recurso `ConfigMap`
. Namespace: `openshift-monitoring`
. *Create ConfigMap* → pestaña *YAML* → pega el manifiesto (o edita `cluster-monitoring-config` si ya está)
. `data.config.yaml`:

[source,yaml]
----
enableUserWorkload: true
alertmanagerMain:
  enableUserAlertmanagerConfig: true
----

. *Save* / *Create*

== Verificar

[source,bash]
----
oc get cm cluster-monitoring-config -n openshift-monitoring -o yaml
oc get pods -n openshift-user-workload-monitoring
----

Pods `Running`.
