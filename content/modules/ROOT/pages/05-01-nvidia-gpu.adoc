= NVIDIA GPU Operator

Instala el *NVIDIA GPU Operator* cuando tengas (o vayas a tener) nodos con GPU real.
Si tu cluster es single-node solo CPU, omite este menú y usa xref:05-02-fake-gpu.adoc[Fake GPU Operator].

En OpenShift, *Node Feature Discovery* (*NFD*) es **requisito** del GPU Operator: etiqueta nodos con PCI NVIDIA (`feature.node.kubernetes.io/pci-10de.present=true`) para que el Operator sepa dónde desplegar drivers y device plugins.

Documentación:

* https://docs.nvidia.com/datacenter/cloud-native/openshift/latest/install-nfd.html[Instalar NFD (NVIDIA)]
* https://docs.nvidia.com/datacenter/cloud-native/openshift/latest/install-gpu-ocp.html[Instalar NVIDIA GPU Operator]

Orden: *NFD Operator* → instancia `NodeFeatureDiscovery` → *NVIDIA GPU Operator* → `ClusterPolicy` → GPU Administrator plugin → MIG (opcional) → hardware profile.

== Validar operadores

Ejecuta esto *antes* de instalar (y otra vez al final). `OK` = CSV `Succeeded`; `PENDIENTE` = aún no está o no terminó.
Si ya hay `OK`, omite esa instalación y sigue al CR (`NodeFeatureDiscovery` / `ClusterPolicy`).

[source,bash]
----
printf '%-42s %-14s\n' "OPERADOR" "ESTADO"
printf '%-42s %-14s\n' "------------------------------------------" "--------------"
check() {
  local name="$1" pattern="$2"
  local line phase
  line=$(oc get csv -A --no-headers 2>/dev/null | grep -iE "$pattern" | head -1)
  if [ -z "$line" ]; then
    printf '%-42s %-14s\n' "$name" "PENDIENTE"
  else
    phase=$(echo "$line" | awk '{print $NF}')
    if [ "$phase" = "Succeeded" ]; then
      printf '%-42s %-14s\n' "$name" "OK"
    else
      printf '%-42s %-14s\n' "$name" "$phase"
    fi
  fi
}
check "Node Feature Discovery" "nfd"
# certified = NVIDIA real (excluye el CSV falso gpu-operator-fake del Fake GPU)
check "NVIDIA GPU Operator" "gpu-operator-certified"
----

== Validar candidatos (antes / después de NFD)

Antes de NFD puede no haber labels. Tras NFD + ClusterPolicy deberías ver GPU allocatable.

[source,bash]
----
oc get nodes -o json | jq -r '
  .items[] |
  select(
    (.status.allocatable["nvidia.com/gpu"] != null)
    or (.metadata.labels["feature.node.kubernetes.io/pci-10de.present"] == "true")
    or ((.metadata.labels["nvidia.com/gpu.product"] // "") != "")
  ) |
  .metadata.name
'
----

== NFD Operator (recomendado / requerido)

Si el validador ya muestra `OK` para *Node Feature Discovery*, salta a <<nfd-cr>>.

. Consola → *Ecosystem* → *Software Catalog*
. Busca `Node Feature Discovery`
. Instala en el namespace recomendado (suele ser `openshift-nfd`)
. Espera *Succeeded*

Vuelve a ejecutar el comando de *Validar operadores* hasta ver `OK`.

[#nfd-cr]
== NodeFeatureDiscovery (CR)

El ejemplo oficial sale del CSV del Operator (la imagen `operand` depende de la versión de OpenShift). Consíguelo y aplícalo:

[source,bash]
----
oc get csv -n openshift-nfd -o jsonpath='{.items[0].metadata.annotations.alm-examples}' \
  | jq 'map(select(.kind == "NodeFeatureDiscovery")) | .[0]' \
  > /tmp/nodefeaturediscovery.json

oc apply -f /tmp/nodefeaturediscovery.json
----

Espera pods de NFD y labels NVIDIA en nodos con GPU:

[source,bash]
----
oc get pods -n openshift-nfd
oc get nodes -L feature.node.kubernetes.io/pci-10de.present
----

En nodos con GPU real debería verse `true` en esa columna.

== NVIDIA GPU Operator

Si el validador ya muestra `OK` para *NVIDIA GPU Operator*, salta a <<clusterpolicy>>.

. Consola → *Ecosystem* → *Software Catalog*
. Busca `NVIDIA GPU Operator`
. Instala en el namespace recomendado (suele ser `nvidia-gpu-operator`)
. Espera *Succeeded*

Vuelve a ejecutar el comando de *Validar operadores* hasta ver `OK` en ambos.

[#clusterpolicy]
== ClusterPolicy

Igual que NFD: el manifiesto de ejemplo depende de la versión del Operator. Extráelo del CSV y aplícalo (nombre típico `gpu-cluster-policy`):

[source,bash]
----
oc get csv -n nvidia-gpu-operator -o jsonpath='{.items[0].metadata.annotations.alm-examples}' \
  | jq 'map(select(.kind == "ClusterPolicy")) | .[0]' \
  > /tmp/clusterpolicy.json

oc apply -f /tmp/clusterpolicy.json
----

Sigue el despliegue del stack (driver, device plugin, GFD, etc.):

[source,bash]
----
oc get clusterpolicy -A
oc get pods -n nvidia-gpu-operator
----

== Verificar GPU en nodos

[source,bash]
----
oc get nodes -o custom-columns=\
NAME:.metadata.name,\
GPU:.status.allocatable.nvidia\.com/gpu,\
PRODUCT:.metadata.labels.nvidia\.com/gpu\.product,\
NFD:.metadata.labels.feature\.node\.kubernetes\.io/pci-10de\.present
----

Esperado: al menos un worker con `GPU` ≥ `1`.

IMPORTANT: *No* etiquetes esos nodos con `run.ai/simulated-gpu-node-pool` (eso es solo Fake GPU).

== GPU Administrator (Compute → GPUs)

Plugin de consola
https://github.com/rh-ecosystem-edge/console-plugin-nvidia-gpu[`console-plugin-nvidia-gpu`]:
menú *Administrator* → *Compute* → *GPUs* con métricas DCGM del NVIDIA GPU Operator.
OpenShift *4.20+* → chart `0.3.0`. Namespace: `nvidia-gpu-operator`.

[source,bash]
----
helm repo add rh-ecosystem-edge \
  https://rh-ecosystem-edge.github.io/console-plugin-nvidia-gpu
helm repo update

helm upgrade -i console-plugin-nvidia-gpu \
  rh-ecosystem-edge/console-plugin-nvidia-gpu \
  --namespace nvidia-gpu-operator \
  --version 0.3.0

# habilitar el plugin (sin pisar otros plugins ya listados)
oc get consoles.operator.openshift.io cluster -o json \
  | jq '.spec.plugins = ((.spec.plugins // []) + ["console-plugin-nvidia-gpu"] | unique)' \
  | oc apply -f -

# métricas DCGM que pide el plugin (ConfigMap del chart)
oc patch clusterpolicies.nvidia.com gpu-cluster-policy --type=merge \
  -p '{"spec":{"dcgmExporter":{"config":{"name":"console-plugin-nvidia-gpu"}}}}'
----

Si el `ClusterPolicy` no se llama `gpu-cluster-policy`, usa el nombre de `oc get clusterpolicy -A`.

Verificar:

[source,bash]
----
oc get consoleplugin console-plugin-nvidia-gpu
oc -n nvidia-gpu-operator get deploy,svc -l app.kubernetes.io/name=console-plugin-nvidia-gpu
oc get consoles.operator.openshift.io cluster -o jsonpath='{.spec.plugins}{"\n"}'
----

Recarga forzada la consola (Ctrl+Shift+R) → *Compute* → *GPUs*.

NOTE: Este plugin es del camino *NVIDIA real*. En Fake GPU no hace falta (ni el parche de `ClusterPolicy`).

[#mig-real]
== Configurar MIG (NVIDIA real)

Equivalente *operativo* al xref:05-03-gpu-config.adoc[GPU Config Plugin] del Fake: aquí **no** hay ese ConsolePlugin.
MIG lo aplica el *MIG Manager* del NVIDIA GPU Operator
(https://docs.nvidia.com/datacenter/cloud-native/openshift/latest/mig-ocp.html[doc oficial]).

Requisitos: GPU MIG-capable (A100, A30, H100, H200, …), nodos **sin** workloads GPU (drena antes de reconfigurar).

. Estrategia de anuncio (`mixed` = recursos `nvidia.com/mig-*`; `single` = slices como `nvidia.com/gpu`):

[source,bash]
----
STRATEGY=mixed
oc patch clusterpolicy/gpu-cluster-policy --type=json \
  -p="[{\"op\":\"replace\",\"path\":\"/spec/mig/strategy\",\"value\":\"${STRATEGY}\"}]"
----

Si el CR no se llama `gpu-cluster-policy`, usa `oc get clusterpolicy -A`.

. Perfiles disponibles en el nodo (ConfigMap generado o `default-mig-parted-config`):

[source,bash]
----
export NVIDIA_GPU_NODE=$(oc get nodes -o json | jq -r '
  .items[] |
  select((.status.allocatable["nvidia.com/gpu"] // "0") != "0"
    and .status.allocatable["nvidia.com/gpu"] != null) |
  .metadata.name' | head -1)
echo "NVIDIA_GPU_NODE=${NVIDIA_GPU_NODE}"

oc get cm -n nvidia-gpu-operator "${NVIDIA_GPU_NODE}-mig-config" -o name 2>/dev/null \
  || oc get cm -n nvidia-gpu-operator default-mig-parted-config -o name
----

. Aplicar un perfil (ejemplo; el nombre exacto depende del GPU — mira el ConfigMap):

[source,bash]
----
# ejemplos típicos: all-disabled | all-balanced | all-1g.10gb | all-2g.20gb …
MIG_CONFIGURATION=all-balanced
oc label node "${NVIDIA_GPU_NODE}" \
  "nvidia.com/mig.config=${MIG_CONFIGURATION}" --overwrite
----

. Esperar a que el MIG Manager termine:

[source,bash]
----
oc get node "${NVIDIA_GPU_NODE}" -o jsonpath='{.metadata.labels.nvidia\.com/mig\.config}{"\n"}{.metadata.labels.nvidia\.com/mig\.config\.state}{"\n"}'
oc get node "${NVIDIA_GPU_NODE}" -o json | jq -r '
  .status.allocatable |
  to_entries[] |
  select(.key | startswith("nvidia.com/")) |
  "\(.key)=\(.value)"'
----

Esperado: `nvidia.com/mig.config.state=success` y recursos `nvidia.com/mig-…` (o `nvidia.com/gpu` si usaste `single`).

Para volver a GPU completa:

[source,bash]
----
oc label node "${NVIDIA_GPU_NODE}" nvidia.com/mig.config=all-disabled --overwrite
----

NOTE: El xref:05-03-gpu-config.adoc[GPU Config Plugin] de rhpds solo habla con Fake (`gpu-operator`). No lo apuntes a `nvidia-gpu-operator`.

== Hardware profile

Crea el profile `nvidia-gpu` (1× `nvidia.com/gpu`):

[source,bash]
----
oc apply -f manifests/hardware-profile-nvidia.yaml
oc get hardwareprofile nvidia-gpu -n redhat-ods-applications
----

Si habilitaste MIG y quieres un profile por slice, clona el YAML y cambia el identifier a p. ej. `nvidia.com/mig-1g.18gb` (el nombre exacto debe coincidir con lo anunciado en el nodo).
