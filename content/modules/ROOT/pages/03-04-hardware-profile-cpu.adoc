= Hardware profile CPU

El profile `cpu-workshop` es el que usa este lab para desplegar Qwen (sin GPU).
Créalo *después* del Operator, el `DataScienceCluster` y el `ODHDashboardConfig`, cuando ya exista el namespace `redhat-ods-applications`.

== Qué se crea

[cols="1,2"]
|===
|Campo |Valor

|Nombre
|`cpu-workshop`

|Namespace
|`redhat-ods-applications`

|CPU
|min 1, default 2, max 2

|Memory
|min 2Gi, default 8Gi, max 8Gi

|GPU
|ninguna
|===

== Instalar por terminal

[source,bash]
----
oc apply -f manifests/hardware-profile-cpu.yaml
----

== Verificar

[source,bash]
----
oc get hardwareprofile cpu-workshop -n redhat-ods-applications
----

En el dashboard: *Settings* → *Hardware profiles* → debe aparecer `cpu-workshop`.
