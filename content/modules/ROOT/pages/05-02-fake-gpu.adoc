= Fake GPU Operator

Simula `nvidia.com/gpu` (y MIG) en un *worker solo CPU*.
Úsalo en single-node CPU, o en workers CPU de un cluster híbrido.
*No* lo uses en un single-node que ya tenga GPU real (ahí solo xref:05-01-nvidia-gpu.adoc[NVIDIA GPU Operator]).

Emula **una NVIDIA H200 141GB HBM3e** recortada con MIG:

[cols="1,1,1"]
|===
|Slice |Recurso |Cantidad

|1g.18gb
|`nvidia.com/mig-1g.18gb`
|2

|2g.35gb
|`nvidia.com/mig-2g.35gb`
|1

|3g.71gb
|`nvidia.com/mig-3g.71gb`
|1
|===

El worker también anuncia la GPU completa (`nvidia.com/gpu=1`) para GPU Booking y el profile `fake-h200`.

== Elegir un nodo CPU

[source,bash]
----
export CPU_WORKER_NODES=$(oc get nodes -l node-role.kubernetes.io/worker -o json | jq -r '
  .items[] |
  select((.status.allocatable["nvidia.com/gpu"] // "0") == "0"
    or .status.allocatable["nvidia.com/gpu"] == null) |
  .metadata.name
' | tr '\n' ' ')

export FAKE_GPU_NODE=$(echo "$CPU_WORKER_NODES" | awk '{print $1}')
echo "FAKE_GPU_NODE=${FAKE_GPU_NODE}"
test -n "$FAKE_GPU_NODE" && echo "OK: nodo = $FAKE_GPU_NODE" || echo "SKIP: no hay worker CPU libre"
----

Si `FAKE_GPU_NODE` está vacío, omite el resto de este menú.

Comprueba que no tenga GPU real anunciada:

[source,bash]
----
oc get node "$FAKE_GPU_NODE" -o jsonpath='{.status.allocatable.nvidia\.com/gpu}{"\n"}'
----

Debe estar vacío o `0`.

== Etiquetar nodo y namespace

[source,bash]
----
oc label node "$FAKE_GPU_NODE" run.ai/simulated-gpu-node-pool=default --overwrite

oc create namespace gpu-operator
oc label ns gpu-operator \
  pod-security.kubernetes.io/enforce=privileged \
  pod-security.kubernetes.io/audit=privileged \
  pod-security.kubernetes.io/warn=privileged \
  --overwrite
----

== Instalar Fake GPU (Helm)

Namespace `gpu-operator` = Fake (distinto de `nvidia-gpu-operator`). Desde la raíz del repo:

[source,bash]
----
helm upgrade -i gpu-operator \
  oci://ghcr.io/run-ai/fake-gpu-operator/fake-gpu-operator \
  --namespace gpu-operator \
  --version 0.2.0 \
  -f manifests/fake-gpu-values.yaml
----

Si cambias la topología *después* del install:

[source,bash]
----
oc delete cm "topology-${FAKE_GPU_NODE}" -n gpu-operator --ignore-not-found
oc delete pod -n gpu-operator -l app=device-plugin
oc delete pod -n gpu-operator -l app=status-updater
----

== Verificar

[source,bash]
----
oc get pods -n gpu-operator
oc get node "$FAKE_GPU_NODE" -o custom-columns=\
NAME:.metadata.name,\
PRODUCT:.metadata.labels.nvidia\.com/gpu\.product,\
GPU:.status.allocatable.nvidia\.com/gpu,\
MIG1:.status.allocatable.nvidia\.com/mig-1g\.18gb,\
MIG2:.status.allocatable.nvidia\.com/mig-2g\.35gb,\
MIG3:.status.allocatable.nvidia\.com/mig-3g\.71gb
----

Esperado: `NVIDIA-H200-141GB-HBM3e`, `nvidia.com/gpu=1`, y los slices MIG.

== Hardware profiles

Profiles de este camino (no incluye `nvidia-gpu` ni `cpu-workshop`):

* `fake-h200`: 1× `nvidia.com/gpu`
* `fake-h200-mig`: 1× `nvidia.com/mig-1g.18gb`

[source,bash]
----
oc apply -f manifests/hardware-profiles-fake.yaml
----

Verificar:

[source,bash]
----
oc get hardwareprofile -n redhat-ods-applications fake-h200 fake-h200-mig
----
